# Donlaphon Chueaho — Personal Portfolio

เว็บไซต์ Portfolio แบบ Single Page Application (SPA) สำหรับแนะนำตัว ทักษะ ผลงาน และช่องทางติดต่อ ออกแบบให้ใช้งานได้ทั้งคอมพิวเตอร์และโทรศัพท์มือถือ

## เกี่ยวกับโปรเจกต์

เว็บไซต์นี้รวบรวมข้อมูลของ **ตัวผม** นักศึกษาด้าน Software Engineering ที่สนใจการออกแบบระบบ การเชื่อมต่อ API และการทำงานอัตโนมัติ

ภายในหน้าเดียวแบ่งเนื้อหาออกเป็นส่วนต่าง ๆ เพื่อให้ผู้ชมเลือกดูได้ง่าย:

- **Home** — แนะนำชื่อและบทบาท
- **Work** — แสดงผลงานเด่นและรายการ Repository จาก GitHub
- **What I Can Do** — แสดงภาษาและเครื่องมือที่ใช้
- **About Me** — ประวัติและสิ่งที่กำลังเรียนรู้
- **Trainings & Activities** — กิจกรรมและการอบรม
- **Contact** — ช่องทางติดต่อและแบบฟอร์มตัวอย่าง


## เทคโนโลยีที่ใช้สร้างเว็บไซต์

- **HTML5** สำหรับโครงสร้างและเนื้อหา
- **CSS3** สำหรับการจัดวางและ Responsive Design
- **JavaScript** สำหรับเมนู, carousel, ธีม และการแสดงข้อมูลแบบโต้ตอบ
- **GitHub REST API** สำหรับโหลดข้อมูล Repository สาธารณะ
- **Bootstrap CSS** สำหรับองค์ประกอบบางส่วน และ **Bootstrap Icons** สำหรับไอคอน

## หมายเหตุ

- เว็บไซต์เป็น SPA โดยเมนูจะเลื่อนไปยังหัวข้อภายในหน้าเดียวกัน
- ส่วน Repository จะแสดงเมื่อกด **View Project** และดึงเฉพาะข้อมูลสาธารณะจาก GitHub
- แบบฟอร์มติดต่อเป็นตัวอย่างหน้าตาและการโต้ตอบ ยังไม่ได้เชื่อมต่อระบบส่งข้อความจริง
